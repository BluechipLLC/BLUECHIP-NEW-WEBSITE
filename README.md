# BLUECHIP NEW WEBSITE

Bluechip Branding & Design website wireframe, including the responsive interactive portfolio board and founder contact section.

## Run locally

Requires Node.js 20 or newer. No dependencies to install.

```sh
npm run dev
```

Open http://localhost:4173.

## Check

```sh
npm run check
node tests/board-layout.test.mjs
```

## Project structure

- `dist/`: website HTML, CSS, and JavaScript
- `server.mjs`: local preview server
- `tests/`: portfolio layout checks

This is a wireframe with flat-color project placeholders. The personal founder phone CTA remains inactive until a number is explicitly approved. The existing inquiry experience is retained. Uploading this repository does not deploy the website.
